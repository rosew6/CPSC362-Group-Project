How to run code:

Open Visual studio developer command prompt:
     Tools -> command line -> developer command prompt

Open the module 6 folder:
     Ex. for me it is cd /d "C:\Users\Owner\source\repos\rosew6\CPSC362-Group-Project\Module 6"

Compile the program:
     cl /std:c++17 /EHsc /W4 Pushdown_Automaton_Simulator.cpp /Fe:Pushdown_Automaton_Simulator.exe

Run tests:
     Pushdown_Automaton_Simulator.exe --test
